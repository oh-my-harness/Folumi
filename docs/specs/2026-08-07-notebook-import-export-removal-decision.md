# 移除笔记导入与导出

日期：2026-08-07

## 决策

Folumi 不再提供笔记导入、单篇导出、ZIP 备份或 Obsidian Vault 导出功能。设置页删除对应入口，后端不再注册相关 HTTP 接口。

## 原因

笔记库本身就是用户选择的本地 Markdown 文件夹。用户可以直接通过文件系统或其他编辑器复制、移动和备份内容，再维护一套应用内导入导出流程只会造成概念重复和额外维护成本。

## 保留能力

- 添加、重命名、切换和移除多个笔记库；
- 直接读写笔记库中的 Markdown 文件；
- 文件树、目录、搜索、Wiki 链接、标签和反向链接；
- 助手在用户授权下读取或修改当前会话关联的笔记库。

移除笔记库仍然只解除 Folumi 的关联，不会删除磁盘文件。
