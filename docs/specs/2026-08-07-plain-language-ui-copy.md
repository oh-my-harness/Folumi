# 界面文案通俗化规范

状态：已接受
日期：2026-08-07

## 决策

Folumi 面向普通个人用户。主界面文案应优先说明“用户可以做什么”和
“选择后会发生什么”，不得用实现方式代替产品解释。

高频界面采用以下规则：

1. 普通页面标题尽量使用日常动作或对象，例如“资料”“笔记”“联网搜索”。
2. 一条说明只表达一个主要结果，中文通常不超过 25 个字。
3. 不在页面简介、开关说明、空状态和首次引导中直接使用 RAG、Agent、
   embedding、向量、上下文、runtime、scope、Vault、入库等内部术语。
4. 设置等配置界面保留行业通用的准确名称，包括 LLM、嵌入模型、API Key、
   Base URL、模型 ID 和 tokens；这些字段的说明仍使用简短的普通语言。
5. 重要限制直接说明结果，不展开内部规则。例如“自动记住你明确说过的重要信息。
   敏感内容仍会询问你。”
6. 帮助页可以比主界面详细，但仍先给出任务步骤；实现原理只放在开发文档或
   面向高级用户的展开区域。
7. 中文与英文文案表达相同含义，不能让某一种语言承担额外的产品规则。

## 用户词汇与内部词汇

| 用户界面 | 内部实现或开发文档可使用 |
| --- | --- |
| 普通页面中的“回答模型” | 设置中的 LLM provider/profile |
| 普通页面中的“资料查找” | 设置中的嵌入模型，以及开发文档中的 vector retrieval、RAG |
| 添加文档 | ingest、indexing |
| 查找、重新整理 | retrieval、reindex |
| 笔记保存位置、外部文件夹 | Notebook root、Vault |
| 助手 | Agent、runtime agent |
| 以前聊过的内容 | history recall、session scope |

内部 API、类型名、数据库字段和 runtime 边界不因此重命名；这是一项用户界面
语言决策，而不是架构迁移。

## 验收要求

- 个性化页面的三个主要开关均使用单句短说明。
- 首次引导不出现 RAG、嵌入、向量或 Agent。
- 设置导航保留“LLM”“嵌入模型”等准确配置名称。
- 资料页的普通操作使用“添加”“查找”“重新整理”，技术配置字段仅在设置中出现。
- 新增用户可见文案时，应同时检查中文长度、英文含义和窄窗口下的阅读密度。
