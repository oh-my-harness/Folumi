# Notebook 块级实时预览编辑决策

> 状态：已接受并实现
> 日期：2026-08-06
> 范围：Notebook Markdown 阅读、编辑与保存交互

## 决策

Notebook 使用块级 Live Preview 作为默认且唯一的正文编辑方式。

- Markdown 标题、段落、列表、引用、表格、公式和代码块在未聚焦时保持渲染状态；
- 点击一个渲染块后，仅该块显示 Markdown 源码并可直接编辑；
- 离开当前块或停止输入后恢复渲染，并在短暂防抖后自动保存；
- `Ctrl+S` / `Cmd+S` 仍可立即触发保存，但不再依赖顶部保存按钮；
- 编辑器顶部不再显示“编辑”“保存”“取消”或“删除”操作栏；
- 笔记删除、重命名和目录管理统一由文件树承担；
- 保存仍使用精确 revision，外部修改造成冲突时不得静默覆盖；
- 保存状态以低干扰文字显示，不创建额外消息或弹窗。

## Markdown 链接规则

- Markdown 标题生成的 `#anchor` 是当前文档内的页内锚点，桌面端不得将其交给系统浏览器；
- Notebook Live Preview 中的标题不显示为可跳转链接，点击标题应进入该标题块的编辑状态；
- `http:`、`https:` 和 `mailto:` 等显式外部链接仍由桌面端外部浏览器打开；
- Wiki 链接和产品来源链接继续使用各自的产品内导航。

## 原因

Notebook 是持续书写空间，不应要求用户在“预览”和“整篇源码编辑”之间频繁切换。块级 Live Preview 同时保留 Markdown 的可控性和渲染后的阅读体验，也使顶部编辑和删除按钮失去必要性。

## 回归要求

1. 点击 Notebook 标题不得打开网页。
2. 点击普通渲染块后，只出现一个当前块源码输入框。
3. 代码围栏内的空行不得把代码块错误拆开。
4. 块编辑不得改变当前块之外的 Markdown 字节。
5. 自动保存必须串行执行，并继续使用最新 revision。
6. 文件树仍提供删除、重命名和目录操作。
