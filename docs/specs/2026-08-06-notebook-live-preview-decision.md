# Notebook 即时渲染编辑决策

> 状态：已接受并实现
> 日期：2026-08-06
> 修订：2026-08-07
> 范围：Notebook Markdown 阅读、编辑与保存交互

## 决策

Notebook 使用 Vditor 的即时渲染（`ir`）模式作为默认且唯一的正文编辑方式。Markdown 文件仍是持久化事实源，不引入第二套产品数据格式。

- 未激活的 Markdown 块正常渲染；光标进入块后显示该块的 Markdown 原文本和定界符；
- 标题未激活时按标题渲染，进入标题后才显示对应数量的 `#`；
- 标题、段落、列表、引用、表格、公式和代码块位于同一个连续编辑面；
- 不使用产品拼装的块级 `textarea`，不在渲染块与临时输入框之间切换；
- 不显示选区浮动格式栏、块拖拽控件或顶部编辑工具条，避免遮挡内容和干扰拖选；
- 内容变化后防抖自动保存，编辑器失焦时立即提交尚未保存的内容；
- `Ctrl+S` / `Cmd+S` 可立即保存，但不依赖顶部保存按钮；
- 保存继续使用精确 revision，外部修改造成冲突时不得静默覆盖；
- YAML Front Matter 不进入正文编辑面，保存时原样拼回；
- 保存状态仅以低干扰文字显示。

## 技术选型

- 采用 [Vditor](https://b3log.org/vditor/) 的 `ir` 模式；该模式的产品语义就是即时渲染，而不是纯 WYSIWYG；
- Vditor 采用 MIT 许可证，编辑器与渲染资源随桌面包本地分发，不依赖公网 CDN；
- 禁用 Vditor 自身缓存，由 Folumi 的 Notebook 保存链路和 revision 冲突控制负责持久化；
- 禁用工具栏、计数器、尺寸拖拽和链接直接打开，保留连续选择、撤销/重做、粘贴和输入法处理；
- 暂不启用图片上传。图片持久化需要先确定 Vault 资源目录和相对路径规则；
- Notebook 的 AI 写入继续使用现有产品链路，不接入编辑器厂商的 AI 功能。

## Markdown 兼容边界

第一阶段必须覆盖：

1. CommonMark 与 GFM，包括表格、任务列表和围栏代码块语言；
2. 行内及块级数学公式；
3. `[[目标]]` 与 `[[目标|别名]]` Wiki 链接，不把 `![[资源]]` 误判为笔记；
4. Wiki 链接在编辑态使用 `Ctrl/Cmd + 点击`打开，普通点击只定位光标；
5. 空笔记、中文输入法、跨段选择、撤销/重做和粘贴；
6. 文件开头的 YAML Front Matter 作为不可见文件元数据剥离并原样拼回；
7. HTML 注释及扩展语法必须经过往返测试；无法无损表达时保留源码，不能静默删除。

## Markdown 链接规则

- Markdown 标题生成的 `#anchor` 是文档内锚点，桌面端不得将其交给系统浏览器；
- 标题点击用于定位和编辑，不得打开网页；
- `http:`、`https:` 和 `mailto:` 等显式外部链接仍由桌面端外部浏览器打开；
- Wiki 链接和产品来源链接继续使用产品内导航。

## 原因

Notebook 是持续书写空间，不应要求用户手动切换“预览”和“源码”。纯 WYSIWYG 会隐藏 Markdown 层级和定界符；永久显示伪造的 `#` 又不符合即时渲染预期。`ir` 模式直接提供“未激活块渲染、当前块显示源码”的交互，也避免重新实现编辑器级选区、输入法、撤销栈和块渲染。

## 回归要求

1. 未激活标题不显示 `#`，光标进入标题后显示准确的 Markdown 原文本。
2. 当前编辑块显示其 Markdown 定界符，离开后恢复渲染。
3. 拖动选择正文时不得弹出格式浮动栏或块操作控件，也不得发生布局抖动。
4. 正文使用适合桌面工作区的紧凑排版。
5. 用户可以连续选择和修改多个段落，并正常撤销/重做。
6. CommonMark、GFM、公式和 Wiki 链接必须通过 Markdown 往返测试。
7. 自动保存必须串行执行并使用最新 revision；保存冲突不得覆盖外部修改。
8. 文件树继续承担删除、重命名和目录操作。

## 被替代方案

- “渲染块 + 点击后显示单块 textarea”破坏连续光标和跨块选择，不保留；
- Milkdown Crepe 纯 WYSIWYG 方案隐藏 Markdown 源定界符，不符合即时渲染需求；
- 用 CSS 永久添加标题 `#` 只能伪造局部源码，也会让未选中标题不再是正常渲染，因此撤销。

## 实现验收

- 自动化测试覆盖 YAML Front Matter、Wiki 链接范围和保存边界；
- 产品外壳回归测试确认使用 `ir` 模式、按需加载、无顶部工具栏和块级 `textarea`；
- 本地端到端验证必须确认标题在未激活和激活状态间正确切换，并检查拖选、保存及 Markdown 往返；
- 等价 Markdown 可以规范化空白，但产品扩展不得丢失。
