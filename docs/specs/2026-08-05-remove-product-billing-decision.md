# 移除产品内货币费用与预算控制决定

> 状态：已接受
> 日期：2026-08-05

## 决定

Folumi 不再提供按会话计费、全局美元费用汇总或美元预算上限功能，并从产品界面、设置、会话协议和 benchmark 新结果中移除相关字段。

Folumi 继续保留 provider/runtime 返回的 token 使用量与上下文容量信息，用于上下文管理、压缩判断、诊断和 benchmark。这些工程指标不再被换算为美元，也不承担账单或消费限额的含义。

## 原因

- 按会话费用对个人知识助手的实际决策价值有限，且容易与服务商账单中的项目、组织或账户级消费混淆。
- Folumi 支持官方服务、自定义 OpenAI-compatible 接口、代理渠道和本地模型；同一个模型名称可能对应不同价格，产品无法稳定推导可信费用。
- provider 可能缺失或延迟返回 usage，显示 `$0.0000` 会把“未知”错误表达为“免费”。
- 全局费用若不能与服务商账单、退款、缓存计价和价格变更保持一致，容易制造错误安全感。
- 美元硬预算需要覆盖普通对话、工具循环、Research 多步骤工作流和中止恢复；这会引入与核心知识助手体验不相称的复杂度。

## 产品边界

删除：

- 助手顶栏中的美元费用与进度条；
- 设置中的 Session budget / 美元预算；
- `budgetLimitUsd`、`budget_limit_usd` 和 `budget_warning` 产品协议；
- `runtime_usage` 与 LoCoMo 新报告中的 `cost_usd` 字段；
- 产品侧为未来预算控制保留的空配置。

保留：

- runtime `usage()` 提供的输入、输出、缓存和推理 token 统计；
- 当前上下文容量提示；
- benchmark 中的 token、延迟、正确性和工具行为指标；
- runtime 自身的通用成本与预算机制，但 Folumi 不对其建立产品依赖。

## 兼容策略

旧 `settings.json` 中的 `budgetLimitUsd` 会在读取时被忽略并在下次保存时消失。旧会话元数据中的 `budget_limit_usd` 由 Serde 作为未知字段忽略，不需要迁移脚本。

## 重新评估条件

只有在出现明确的全局消费管理需求，并且 provider 能提供可验证、可聚合且与账单一致的费用数据时，才重新评估费用功能。届时应设计独立的全局 Usage 页面，而不是重新放回会话顶栏。
