# 多笔记库与切换设计

日期：2026-08-08
状态：已接受

## 用户界面

产品界面使用“笔记库”，不要求普通用户理解 Vault。笔记页面右上角以“当前笔记库 + 下拉箭头”的切换器替代常驻刷新按钮。下拉列表显示已配置的笔记库、当前项和不可访问状态，并提供进入设置管理的入口。

正常文件变化由目录监听处理，不保留常驻手动刷新。重新扫描只作为同步失败时的恢复动作。

“设置 > 笔记”可以添加、重命名、切换和移除多个笔记库。移除仅解除 Folumi 中的关联，绝不删除磁盘文件。相同路径或互相嵌套的路径不得重复配置。

## 数据模型

每个笔记库包含稳定 ID、显示名称、根目录和独立索引。配置保存 `vaults` 列表与 `active_vault_id`；当前单目录配置自动转换为第一个笔记库，不移动用户文件。

笔记身份由笔记库 ID 与库内条目 ID 共同确定。不同笔记库各自保留文件树、目录、恢复区、Wiki 链接、反向链接和监听状态。

## 会话边界

会话关联笔记时保存具体的 `notebook_vault_id`，而不是只保存一个模糊的布尔开关。切换笔记页面的当前笔记库不会改变已有会话的资料范围。

第一版每个会话最多关联一个笔记库，同时仍可关联多个资料集。输入框的“关联资料”列表展示所有笔记库；点击当前笔记库可取消，点击另一个笔记库可切换。后续如需同时检索多个笔记库，再在真实使用数据支持下扩展为列表。

## 验收标准

- 现有笔记目录和文件不迁移、不丢失；
- 设置中可以配置多个不同且不嵌套的目录；
- 笔记页面可以从右上角随时切换笔记库；
- 切换前完成当前编辑保存，切换后文件树和编辑器属于新笔记库；
- 移除笔记库不删除任何文件；
- 会话重开后仍使用创建时关联的具体笔记库；
- 已有关联笔记的旧会话自动绑定到升级时的默认笔记库。
